### Problems I've taken apart

#### Club attendance → [Tapin](https://github.com/Thirdline-LLC/NFC-Attendance-Scanner)

My club had no attendance record, so there was no way to show turnout when asking the school for more adult supervisors. The school already had NFC ID cards, and a reader types each card's code like a keyboard. Version one was a plain Excel workbook with no scripts, so IT had nothing to vet. Version two is Tapin: a kiosk app for Mac, Android and the web where every tap stays on the device and the school's own workbook stays the system of record. It's heading into testing with teachers now.

#### Cadet Corps supply → a student IT team

Our Cadet Corps tracked its supply closet in a paper binder. I audited every item type first, then took a proposal for a digital inventory to the corps staff. It grew into a student IT team for the whole corps, approved this fall, that builds and maintains the corps' software and trains younger cadets to take it over.

#### AI in the entrepreneurship program → a curriculum

I pitched an AI build team to St. John's Entrepreneurship program. The first ask, for paid tools, didn't land. The counteroffer was to build an AI literacy course for freshmen and sophomores and compete in the ISTE+ASCD AI Innovator Challenge, so I built the course as an app instead.
